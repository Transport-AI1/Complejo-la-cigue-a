# Complejo La Cigüeña — Experiencia digital

Demo conceptual de una experiencia web premium para Complejo La Cigüeña, Arganda del Rey.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- React Three Fiber / Three.js para el bungalow 3D
- Agente informativo local basado en datos públicos verificados

## Desarrollo
`npm install`
`npm run dev`

Los modelos 3D son recreaciones conceptuales, no planos ni reproducciones exactas del alojamiento. La demo no consulta disponibilidad ni confirma reservas.
